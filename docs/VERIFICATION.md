# Implementation verification log (2026-11-20)

All validation below was performed inside an **installed CPU-only PyTorch environment** with `torch 2.10.0+cpu`; it has **not** been checked on the owner's RTX 5060 Laptop 8GB.

## Passed

1. `PYTHONPATH=src python -m corecpu_lab selftest`: passed all eight model/task combinations (A/B/C/D × STRUCTURED/LANGUAGE), including backwards gradients.
2. `PYTHONPATH=src python -m pytest -q`: **25 tests passed** (factorial forward/backward, no target leakage, sparse dispatch, LM causality, SEC chunk consistency, manual learning, old/new split semantics, deterministic resume and interaction analysis).
3. `python legacy/v0.1/core_cpu.py selftest`: passed the archived source's original nine checks.
4. A/B/C/D structure training: completed `steps=2`, `batch=4`, `eval_batches=1` with checkpoint files.
5. A/B/C/D language training: completed `steps=2`, `batch=2`, `eval_batches=1` with checkpoints (D language smoke repeated separately after an initial batch harness timeout).
6. D structured LOCAL and ELIG training: completed `steps=2`, `batch=4`, `eval_batches=1`.
7. `ff-demo`: executed with a finite local loss.
8. `predict`: loaded a D model checkpoint and emitted three step predictions (untrained/short-trained accuracy is not meaningful).
9. `generate`: loaded a D byte language checkpoint and generated bytes from a prompt.
10. Factorial `benchmark`: A/B/C/D each trained for one step and wrote `results.csv`, per-run JSON/checkpoints and manifest.
11. `analyze`: parsed the factorial CSV and produced seed-paired effects; `profile`: produced measured warm-up forward times at two lengths.

## Explicit limitations

- **No** complete 700-step four-way training or multi-seed benchmark has been performed for this release.
- No claims are made about outperforming baseline models or getting better language modeling results.
- No local CUDA/BF16 verification occurred. Measurements on RTX 5060 require running this repository on the user's device.
- ELIG does not update all neural parameters, as documented; it is intentionally limited.
- The GitHub remote has not been renamed or changed. The ZIP is an importable source tree, not a Git repository or clone.
